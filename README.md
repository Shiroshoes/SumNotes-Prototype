## Project Description
SumNotes is a mobile note-taking application designed to help users create, organize, and manage their notes efficiently. Key features include pinning important notes, viewing deleted notes history, and a smooth, interactive interface. The backend is powered by **Flask** and **SQLite**, while the frontend is built with **React Native**.  

---

## Features
- Create, edit, and delete notes  
- Pin and unpin important notes  
- View deleted notes in history  
- Scrollable note lists for easy navigation  
- Responsive mobile interface
- AI Summarizer per Notes
- Optional dark mode support  

---

## Tech Stack
- **Frontend:** React Native, Expo  
- **Backend:** Python, Flask  
- **Database:** SQLite  
- **APIs & Libraries:** Hugging Face Transformers, SpaCy
- **UI Components:** React Native Elements, Vector Icons
